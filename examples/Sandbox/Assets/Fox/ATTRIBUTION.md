# Animated Fox sample

Unmodified Fox.glb from the existing Mythbreaker model collection, originally
published in the Khronos glTF sample assets:
https://github.com/KhronosGroup/glTF-Sample-Assets/tree/main/Models/Fox

- Model: PixelMannen, 2014 (CC0).
  https://opengameart.org/content/fox-and-shiba
- Rigging and animation: tomkranis, 2014 (CC BY 4.0).
  https://sketchfab.com/3d-models/low-poly-fox-by-pixelmannen-animated-371dea88d7e04a76af5763f2a36866bc
- glTF conversion: AsoboStudio and scurest, 2017 (CC BY 4.0).
  https://github.com/KhronosGroup/glTF-Sample-Models/pull/150#issuecomment-406300118

Licenses: https://creativecommons.org/licenses/by/4.0/
and https://creativecommons.org/publicdomain/zero/1.0/

The engine sample changes placement and scale in its scene; it does not modify
the binary model. Keep this attribution when redistributing the sample asset.
