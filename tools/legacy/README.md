# Archived prototype scripts

These scripts belong to the original RPG prototype and assume its old directory
layout. They are retained for historical reference and are not part of the engine
build. Do not run them against an engine checkout: some replace source files.

Use the CMake commands in the root README to build the current editor, player and
CLI. The preserved RPG entry point is examples/rpg/main.cpp and is excluded from
the default build.
